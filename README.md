# PoemDirector: Dataset and Evaluation Code

This repository provides the dataset access, evaluation scripts, and representative demo videos for the paper:

**PoemDirector: A Multi-Agent Context-Adaptive Instructional Mode Selection Framework for Chinese Classical Poetry Video Generation**

PoemDirector aims to generate instructional videos for Chinese classical poetry by adaptively selecting explanation, visualization, and narration strategies through a multi-agent framework.

## 📂 Dataset

The full dataset contains videos for **100 Chinese classical poems** generated by five different methods:

* **Our_Method**: Our proposed PoemDirector framework.
* **HAV**: Handcrafted Animation Videos created by human experts.
* **Mootion**: Commercial AI generation baseline.
* **ESV**: Explanatory Short Videos baseline.
* **PRV**: Poetry Recitation Videos baseline.

Due to file size limitations, the complete dataset is hosted on Hugging Face.

Please download and unzip **`poem_dataset.zip`** from:

**[Download Dataset via Hugging Face](https://huggingface.co/datasets/userasadfasdf/poem_data/tree/main)**

After unzipping, the dataset is organized by method:

```text id="qgpjcz"
poem_dataset/
├── Our_Method/
├── HAV/
├── Mootion/
├── ESV/
└── PRV/
```

Files in each folder are named by poem title.

## 🧪 Evaluation Code

The `code/` directory contains the scripts used for the automated evaluation metrics reported in the paper.

| File                     | Function / Metric                                                                                                          |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| `poem_eval_script.py`    | Evaluates **Depth of Explanation**, **Knowledge Accuracy**, and **Instructional Clarity** using LLMs on extracted scripts. |
| `poem_eval_keyframes.py` | Evaluates **Aesthetic Coherence** and **Poetic Imagery Restoration** based on sampled video keyframes.                     |
| `poem_eval_video.py`     | Evaluates **Emotional Resonance** using multimodal LLMs on full videos.                                                    |
| `videoscore.py`          | Calculates **VideoScore** for visual quality and dynamic degree assessment.                                                |
| `batch_clip_scoring.py`  | Computes **CLIP scores** for vision-language alignment validation.                                                         |
